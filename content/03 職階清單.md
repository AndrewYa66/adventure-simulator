# 職階清單

角色卡的「職階」欄位請從下表選擇中文名稱填寫。想新增職階，請在角色卡的「審閱意見」提出，由維護者加入。

職階代表角色的「專長」，稱號才是身分。例如村長的職階是「長老」，巡守隊長的職階是「衛兵」。野獸沒有職階，留空即可。

## 戰鬥類（玩家、NPC、魔物都可使用）

| ID | 職階 | 主能力 | 定位 | 玩家可選 |
| --- | --- | --- | --- | --- |
| adventurer | 冒險者 | 平均 | 什麼都會一點 | ✓ |
| warrior | 戰士 | 力量、體質 | 前線輸出 | ✓ |
| scout | 斥候 | 敏捷 | 偵察、先手 | ✓ |
| mage | 法師 | 智力 | 法術輸出 | ✓ |
| priest | 祭司 | 感知 | 治療、輔助 | ✓ |
| rogue | 盜賊 | 敏捷、魅力 | 潛行、開鎖、偷竊 | ✓ |
| envoy | 說客 | 魅力 | 交涉、說服、情報 | ✓ |
| knight | 騎士 | 力量、魅力 | 坦克、統率 | 僅 NPC |
| berserker | 狂戰士 | 力量 | 高攻低防 | 僅 NPC |
| shaman | 薩滿 | 感知 | 部族法術 | 僅 NPC |
| chieftain | 首領 | 依個體 | 魔物或部族領袖 | 僅 NPC |

## 社會類（NPC 專用）

| ID | 職階 | 用途 |
| --- | --- | --- |
| noble | 貴族 | 發布高層任務、掌握領地 |
| diplomat | 使節 | 代表國家談判、拉攏玩家 |
| merchant | 商人 | 交易、貸款、走私 |
| spy | 間諜 | 情報、背叛、栽贓 |
| commander | 將領 | 指揮軍隊、發布軍事任務 |

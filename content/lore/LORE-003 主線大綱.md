## 摘要

人類只剩世界的兩成土地，其餘由魔族與魔獸佔據，而世界本身只靠一套沒有意識的免疫反射保護自己。表面上，這是一個人造勇者打倒魔王、為人類奪回生存空間的故事；暗地裡，王國與邪教徒正以勇者為通道，餵養一個吞噬靈魂的人造神。玩家每一次「奪取」，都在讓自己變強，也在讓人造神更接近完成。（劇情重建設定紀錄 V0.1）

## 詳細內容

### 世界

| 項目 | 設定 |
| --- | --- |
| 局勢 | 人類處於弱勢，魔族與魔獸佔據約八成的世界 |
| 靈魂 | 死後回歸世界本身。被奪取的靈魂永遠無法回歸，世界因此被削弱。（選配）靈魂被大量摧毀的地方會出現環境異變（詳見 LORE-004） |
| 世界的意志 | 沒有意識，只有像免疫反射一樣的選勇者機制，加上靈魂殘響這類零碎現象（詳見 LORE-005） |
| 魔族 | 以力量為上。少數願意做有代價的交易或談判，大多冷血甚至邪惡 |

### 主要角色與勢力

每個勢力都有一個表面身分和一個真相，玩家從前者開始，逐步發現後者。

| 角色／勢力 | 表面 | 真相 |
| --- | --- | --- |
| 主角 | 王國的勇者 | 王國的人造勇者（本人不知情）。身上的刻印是力量流向人造神的通道，也限制他只能奪取魔族 |
| 魔王 | 第一階段要打倒的敵人 | 世界選出的當代勇者，使命是阻止人造神計畫；世界選勇者只看能力、不看善惡 |
| 王國 | 帶領人類對抗魔族 | 和邪教徒合作打造人造神，以為能開創人類的時代。對外宣稱邪教徒是敵人，以公開追捕作為掩護 |
| 邪教徒 | 王國公開追捕的敵人 | 相信人造神能統合世界的靈魂、完成進化（真假無法確定，任何角色都不能證實或否定） |
| 人造神（最終頭目） | — | 靠吞噬靈魂存在 |
| 同伴 | — | 王國指派 1 位：真心相信王國，會向王國回報勇者的狀況，但不知道人造神計畫。主角自己另外找到 1～2 位 |

### 核心機制：奪取

奪取用額外的力量換取更強的最終頭目，是玩家每場戰鬥都要面對的取捨。

| 項目 | 設定 |
| --- | --- |
| 觸發 | 擊殺智慧生物後選擇是否奪取，需要檢定；做出選擇時立即自動存檔 |
| 對象 | 刻印失效前只能奪取魔族；之後可奪取所有智慧生物。智慧越高的種族靈魂越多，特定個體更多；靈魂量是獨立數值，不等於經驗值 |
| 不論成敗 | 靈魂被摧毀並轉化為能量，強化最終頭目。同一份靈魂量在最終頭目身上的作用是主角的 2.5 倍 |
| 成功 | 獲得該單位的專屬技能或額外經驗值，靈魂量累積到主角的奪取量 |
| 失敗 | 察覺力量流向某處，這是線索 |
| 王國的說法 | 祭司稱之為「永遠終結魔族」 |
| 社會後果 | 感知敏銳的種族反感，魔族反而尊敬或畏懼（見下方「對奪取者的反應」）。表現方式待定，候選有黑氣、臭味、壓迫感 |
| 專屬技能的其他來源 | 與魔族交易，或協助魔族後獲得傳授 |
| 強制事件 | 刻印的限制失效，主角發現奪取也能用在人類等智慧生物身上（見下方「強制事件」） |

- 一般擊殺（不選擇奪取）不會強化最終頭目。
- **奪取量**（隱藏參數，又稱靈魂值）：記錄主角摧毀了多少靈魂，影響人物態度、頭目強化與結局。類似《柏德之門 3》的蝌蚪感染程度。

### 對奪取者的反應

同一個行為，在不同對象眼中評價相反：奪取越多，感知敏銳的種族越反感，魔族與生物則越畏懼。

| 對象 | 反應 |
| --- | --- |
| 具名魔族 | 依個性各自設定，角色卡加上「對奪取者的態度」欄位。寫作原則：大多數是畏懼、提防或想利用，少數真心欣賞 |
| 無名魔族、一般敵對生物、魔獸 | 畏懼或逃跑（建議只限比主角弱的對象） |
| 感知敏銳的種族 | 反感 |

### 強制事件

第二幕中段，無論玩家怎麼選，都會發現自己能奪取人類，只是代價大小不同。

| 項目 | 內容 |
| --- | --- |
| 情境 | 王國派勇者追捕邪教徒；被抓的是不知內情的底層成員 |
| 觸發 | 邪教徒施放大範圍的靈魂術式，要殺光所有目擊者，包括無辜村民 |
| 限制 | 術式以施術者的生命為代價發動，只有施術者死亡才會停止（事件當下要讓玩家明白這一點） |
| 殺死他 | 術式中止，刻印失效，勇者不由自主地奪取這個人類的靈魂 |
| 不阻止 | 術式殺死在場的人並收集靈魂，刻印與術式共鳴，將這些靈魂強制吸收 |
| 伏筆 | 聖痕與邪教術式共鳴，暗示兩者出自同一套技術 |
| 系統 | 強制吸收計入奪取量；不阻止時計入的量更多 |

### 遊戲規則與時間壓力

死亡後讀取最後的存檔（一般讀檔制）。時間壓力分兩個階段：前兩幕拖延會失去村莊，第三幕拖延會導致失敗。

| 階段 | 壓力來源 | 結果 |
| --- | --- | --- |
| 第一、二幕 | 魔王軍進攻人類村莊 | 該地毀滅，失去當地的支線與商店，不會導致遊戲失敗 |
| 第三幕 | 人造神完成的倒數（從第三幕開始） | 期限耗盡進入結局 2 |

#### 戰況系統（第一、二幕）

| 項目 | 設定 |
| --- | --- |
| 開始 | 第一幕某個節點之後（建議） |
| 頻率 | 每 10 天進攻一個村莊 |
| 升級 | 每進攻 5 次，下一次改為同時進攻兩處，其中一處由具名魔族帶隊 |
| 目標數量 | 有上限，數量待定 |
| 通報 | 吟遊詩人提前報告戰況 |
| 防衛戰形式 | 擊敗指揮官或精銳部隊（建議） |

### 結局

三個主結局加一個分支，再由兩條變化軸組合出差異。

| 結局 | 觸發 |
| --- | --- |
| 1. 成功阻止人造神計畫 | 在期限內擊敗最終頭目 |
| 1-分支：主角取代人造神 | 結局 1 中，奪取量達門檻且成功奪取魔王時出現選項；以檢定決定成神後的狀態：成神，或被吞噬（轉為結局 2） |
| 2. 阻止失敗 | 期限耗盡，人造神完成 |
| 3. 完成人造神計畫 | 玩家選擇協助王國或邪教徒 |

變化軸：魔王的下場（被殺、被奪取、存活聯手）× 奪取量（少、中、多）。

### 三幕骨架（草案）

前兩幕以討伐魔王為目標，第三幕揭開人造神的真相。

| 幕 | 內容 |
| --- | --- |
| 第一幕 | 接受任命、尋找同伴、第一次奪取、準備討伐魔王 |
| 第二幕 | 深入魔族領地、戰況系統（防衛村莊）、強制事件、與魔王決戰（殺死、奪取或聯手） |
| 第三幕 | 真相揭露、人造神的倒數、選邊、最終戰 |

各幕檔案見 ACT-1～3。

### 保留方案

- **量產勇者**：王國一批又一批地製造人造勇者；死亡後可由下一批接續（遊戲已停用，可能作為日後非同步多人的素材）。
- **記憶繼承**：接續的勇者繼承前一批的部分記憶。
- 前面的內容**不要寫死**「主角是王國唯一的人造勇者」，以便日後接回這兩個方案。

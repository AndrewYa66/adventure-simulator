## 摘要

人類只剩世界的兩成土地，其餘由魔族與魔獸佔據。表面上，這是一個人造勇者打倒魔王、為人類奪回生存空間的故事；暗地裡，王國與邪教徒正以勇者為通道，餵養一個吞噬靈魂的人造神。玩家每一次「奪取」，都在讓自己變強，也在讓人造神更接近完成。（寫手大綱 V0.0）

## 詳細內容

### 世界

| 項目 | 設定 |
| --- | --- |
| 局勢 | 人類處於弱勢，魔族與魔獸佔據約八成的世界 |
| 靈魂 | 死後回歸世界本身。被奪取的靈魂永遠無法回歸，世界因此被削弱。（選配）靈魂被大量摧毀的地方會出現環境異變（詳見 LORE-004） |
| 世界的意志 | 沒有意識，只有像免疫反射一樣的選勇者機制，加上靈魂殘響這類零碎現象（詳見 LORE-005） |
| 魔族 | 以力量為上。少數願意做有代價的交易或談判，大多冷血甚至邪惡 |

### 主要角色與勢力

| 角色／勢力 | 表面 | 真相 |
| --- | --- | --- |
| 主角 | 王國的勇者 | 王國的人造勇者（本人不知情）。身上的刻印是力量流向人造神的通道，也限制他只能奪取魔族 |
| 魔王 | 第一階段要打倒的敵人 | 世界選出的當代勇者，使命是阻止人造神計畫；世界選勇者只看能力、不看善惡 |
| 王國 | 帶領人類對抗魔族 | 和邪教徒合作打造人造神，以為能開創人類的時代 |
| 邪教徒 | — | 相信人造神能統合世界的靈魂、完成進化（真假無法確定，任何角色都不能證實或否定） |
| 人造神（最終頭目） | — | 靠吞噬靈魂存在 |

王國一批又一批地製造人造勇者（背景設定；遊戲的死亡處理採一般讀檔制）。

### 核心機制：奪取

| 項目 | 設定 |
| --- | --- |
| 觸發 | 擊殺智慧生物後選擇是否奪取，需要檢定；做出選擇時立即自動存檔 |
| 對象 | 刻印失效前只能奪取魔族；之後可奪取所有智慧生物。智慧越高的種族靈魂越多，特定個體更多；靈魂量是獨立數值，不等於經驗值 |
| 不論成敗 | 靈魂被摧毀並轉化為能量，強化最終頭目。同一份靈魂量在最終頭目身上的作用是主角的 2.5 倍 |
| 成功 | 主角獲得額外經驗值，靈魂量累積到主角的靈魂值 |
| 失敗 | 主角察覺力量流向某處，這是線索 |
| 王國的說法 | 祭司稱之為「永遠終結魔族」 |
| 社會後果 | 感知敏銳的種族反感，魔族反而尊敬、畏懼，或更傾向挑戰主角、與他交易。表現方式待定，候選有黑氣、臭味、壓迫感 |
| 強制事件 | 刻印的限制失效，主角發現奪取也能用在人類等智慧生物身上 |

- 一般擊殺（不選擇奪取）不會強化最終頭目。
- **靈魂值**（隱藏參數，即「奪取量」）：記錄主角摧毀了多少靈魂，影響人物態度與結局。類似《柏德之門 3》的蝌蚪感染程度。

### 遊戲規則

- 死亡後顯示讀檔訊息，讀取存檔繼續（一般讀檔制）。

### 結局

| 結局 | 條件 |
| --- | --- |
| 1. 成功阻止人造神計畫 | 在期限內擊敗最終頭目 |
| 1-分支：主角取代人造神 | 結局 1 中，靈魂值達門檻且成功奪取魔王時出現選項；以檢定決定成神後的狀態：成神，或被吞噬（轉為結局 2） |
| 2. 阻止失敗 | 期限耗盡，人造神完成 |
| 3. 完成人造神計畫 | 玩家選擇協助王國或邪教徒 |

變化軸：魔王的下場（被殺、被奪取、存活聯手）× 靈魂值（少、中、多）。

### 三幕骨架（草案）

| 幕 | 內容 |
| --- | --- |
| 第一幕 | 接受任命、尋找同伴（王國指派 1 位，真心相信王國；自己找到 1～2 位）、第一次奪取、準備討伐魔王 |
| 第二幕 | 深入魔族領地、強制事件、與魔王決戰（殺死、奪取或聯手） |
| 第三幕 | 真相揭露、人造神的倒數、選邊、最終戰 |

各幕檔案見 ACT-1～3。

### 保留方案

- 量產勇者：死亡後由下一批人造勇者接續（遊戲已停用，可能作為日後非同步多人的素材）。
- 記憶繼承：接續的勇者繼承前一批的部分記憶。

### 待處理

- **待決定**
  - 強制事件的形式（人類敵人，或同伴、熟人）。
  - 期限從何時開始倒數。
  - 魔王被殺後，靈魂循環有什麼反應。
  - 奪取時的表現方式。
  - 魔王是魔族嗎？
  - 靈魂值的門檻（隱藏結局、外顯表現、環境異變），以及是否與善惡傾向混合（系統建議分開記錄，依種族選擇看哪一個）。
  - 結局 2、3 與「結局後世界繼續運作」的衝突：建議結局 1（含成神分支）之後世界繼續運作；結局 2、3 是世界終結的結局，播放尾聲後結束這條時間線，玩家可讀取存檔。
- **待設計**：種族組成（哪些是魔族、哪些有智慧、哪些感應高、各自的靈魂量）、王國與邪教徒的具體樣貌、地理。
- **系統面**：記錄靈魂值（結局、態度、頭目強化、隱藏結局都依賴它，見專案文件 O41）；期限倒數；死亡改為讀檔制（已確認、待實作）。
